updated: october 30th, 2026

a python-based fashion trend analysis tool for independent designers, creatives, and anyone interested in how trends move & fashion culture. this tool combines historical search interest with cultural signals to identify and evaluate emerging fashion trends. 

functionality: type a trend; thread-sght analyzes five years of google search interest and tells you whether it is rising, peaking, steady, fading, seasonal, or just a one-week spike, and how confident that analysis is. 
—-

### main features
- search fashion items, aesthetics, or keywords
- view historical trend data with momentum-based scoring
- identify emerging, stable, or declining trends
- track media and cultural mentions related to each trend
- explore simple future trend projections *(planned)*
